# TU Darmstadt Mensa scraper

Script that automatically scrapes the weekly menu of the canteens at TU Darmstadt and adds everything to a DB.
It's mainly designed to track the pricing of different food items and how often they are offered.
Configuration options include which of the many canteens operated by the Studierendenwerk Darmstadt are scraped. Currently only the TUDa ones are scraped but h_da is also available.
